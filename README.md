# シフトカレンダー登録アプリ

勤務表の画像ファイルから指定スタッフ（デフォルト：皿田）の勤務予定・行事予定をAIと画像処理で抽出し、月間カレンダー確認・調整のうえ Appleカレンダーへ自動登録（または `.ics` 出力）する macOS 専用ローカル Web アプリケーションです。

---

## 主な仕様

| 区分 | アプリ内表示 | Appleカレンダー登録名 | イベント種別 |
| :--- | :--- | :--- | :--- |
| **出勤** | オレンジインジケーター | `[早B] (06:30〜15:30)`（時間有給時は末尾に `（時間有給Xh）` を付記） | 時間指定イベント |
| **休み** | グレーインジケーター | `休み` | 終日イベント |
| **有給休暇** | ピンクインジケーター | `有給休暇` | 終日イベント |
| **行事予定** | 行事予定バッジ | 行事名（祝日・Googleカレンダー標準行事は自動スキップ） | 終日イベント |

---

## 主な機能

1. **右クリックのクイックアクションから一発起動 & 画像自動セット**
   - Finderで勤務表の画像（JPG, PNG, HEIC等）を**右クリック →「クイックアクション」→「シフトカレンダーで読み込む」**を選択するだけでアプリが起動し、画像が自動セットされます。
   - 画像を `シフトカレンダー.app` のアイコンに直接ドラッグ＆ドロップして開くことも可能です。

2. **2タブ構成（カレンダー閲覧タブ / 勤務表の読み込みタブ）**
   - **カレンダータブ**：登録済みシフトを月間カレンダー（日曜始まり）で一覧閲覧でき、前月・次月・年月ピッカー・キーボード矢印・スワイプで素早く移動できます。
   - **勤務表の読み込みタブ**：画像読み込み・AI解析・元画像ビューワー・調整テーブル・Appleカレンダー登録／`.ics` 出力を行います。

3. **カレンダータブからの直接修正（シフト区分・行事予定・時間有給）**
   - カレンダータブで日付をクリックすると詳細カードが開き、その場で**シフト区分の変更・行事予定の編集・時間有給（0.5時間刻み）の設定**を行えます。
   - 「Appleカレンダーにも反映」をオンにして保存すると、該当1日分の Appleカレンダー予定も即座に上書き同期されます。

4. **年間有給カウント & 月単位の勤務集計**
   - 起算日・年間付与日数・1日の有給換算時間を設定モーダルで管理でき、終日有給と時間有給を合算した取得数・残日数をプログレスバー付きで表示します。
   - 月単位での出勤・休み・有給日数もリアルタイム集計されます。

5. **シフト区分定義のUI編集**
   - 設定モーダルからシフト区分（早A〜遅C 等）の追加・時刻変更・削除・標準プリセットへの復元を行えます。
   - 対象者名・登録先カレンダー・外観モード・Gemini APIキーも設定モーダルへ一元化しています。

6. **行事予定の自動抽出 & 日本の祝日・標準行事の自動スキップ**
   - 2段階解析（シフト記号 → 行事予定）により、職場の行事予定を自動抽出し、Googleカレンダーと重複する国民の祝日・一般歳時記は自動スキップします（スキップ一覧はアコーディオンで確認可能）。

7. **重複防止・自動上書き登録 & 登録前確認**
   - 同日に既存予定がある場合は自動で古い予定を削除して最新シフトで上書きします。
   - 登録前に対象カレンダー名・対象期間・件数・上書き注意を確認でき、標準以外のカレンダー名指定時は警告を表示します。
   - `osascript` 実行にはタイムアウトと権限エラー時の設定案内を組み込んでいます。

8. **インタラクティブ元画像ビューワー & 3方向連動**
   - トラックパッドでのピンチ拡大・縮小、ドラッグでのパン移動に対応し、カレンダー・調整テーブル・元画像ビューワーが連動ハイライトします。

9. **凡例クリックによるハイライト連動**
   - 凡例タグ（早A〜遅C、休、有給等）をクリックすると該当シフトのみ強調表示できます。

10. **履歴の自動保存・閲覧・削除 & ZIPバックアップ／復元**
    - 解析結果は自動で履歴に保存され、登録済み履歴と未登録履歴を整理して管理します。
    - 設定モーダルから履歴データ（JSON＋元画像）の **ZIP一括バックアップ** および **非破壊復元（Macローカル限定・既存IDはスキップ）** が行えます。

11. **iPhone連携（ローカル生成QRコード・同一Wi-Fiアクセス）**
    - 外部サービスへ一切送信せず、ローカル生成したQRコードを同一Wi-Fi内のiPhoneカメラで読み取るだけでSafariから利用できます。

12. **外観モード切り替え（システム連動 / ライト / ダーク）**
    - 絵文字を使用しない macOS HIG 準拠のカプセル型デザインで、システム・ライト・ダークの3モードに対応しています。

13. **バックグラウンドプロセスの自動終了 & 静的ファイル構成**
    - ブラウザを閉じるとバックグラウンドプロセスも自動終了します。
    - 外部ビルドツールを使わない軽量構成（`app.py` + `shift_calendar/` + `index.html` + `static/`）を採用しています。

## 起動方法

Finderで **[`シフトカレンダー.app`](file:///Users/saradafumiaki/Documents/Apps/シフトカレンダーapp/シフトカレンダー.app)** をダブルクリックして起動してください。
- ターミナル画面は開かず、ブラウザのみが起動します。
- ブラウザのタブを閉じると、バックグラウンドプロセスも自動終了します。
- （`launch.command` をダブルクリックして起動した場合も同様に終了時に自動で閉じます）
